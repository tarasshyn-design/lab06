## 1. Опис виконаної роботи
У рамках лабораторної роботи було написано три рекурсивні функції на мові C# для обходу заданого дерева категорій:
1. `PrintTree` — виведення всієї ієрархії з відступами відповідно до рівня вкладеності.
2. `CountProducts` — підрахунок загальної кількості товарів у вузлі та всіх його підкатегоріях.
3. `MaxDepth` — обчислення глибини найдовшої гілки дерева.

## 3. Відповіді на питання

1. **Який базовий випадок у вашій функції `CountProducts`? Чому вона завершується?**
   * **Базовий випадок:** Досягнення вузла, у якого колекція дочірніх елементів порожня (`node.Children.Count == 0`). У такому разі цикл не виконується, і функція одразу повертає значення `node.Products`.
   * **Завершення:** Умова зупинки є (вузол без дітей), структура даних скінченна, а на кожному кроці рекурсії ми переходимо до нижчого рівня вкладеності, тому нескінченний цикл виключений.

2. **Скільки разів викликалась `CountProducts` і чому саме стільки?**
   * Функція викликалась **13 разів**, оскільки дерево містить рівно 13 вузлів (категорій), і рекурсивний обхід відвідує кожен із них рівно по одному разу.

3. **Що станеться, якщо у `MaxDepth` прибрати обробку категорії без дітей?**
   * Виникне помилка переповнення стека (`StackOverflowException`), оскільки рекурсія втратить критерій зупинки для кінцевих гілок і нескінченно викликатиме метод для неіснуючих дочірніх елементів.

4. **Для якої з трьох задач рекурсія дає найбільший виграш порівняно з циклом?**
   * Найбільший виграш рекурсія дає для задачі пошуку максимальної глибини (`MaxDepth`) та виведення ієрархії (`PrintTree`), оскільки кількість рівнів вкладеності заздалегідь невідома, і написання ітеративних циклів для довільної вкладеності вимагало б ручного управління стеком.
